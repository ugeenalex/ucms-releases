# UCMS — обновления

Отсюда UCMS берёт новые версии движка: «Настройки сайта → UCMS → Обновления» (веб-версия)
или кнопка обновления в списке проектов (локальная версия). Скачивать вручную ничего не нужно.

- `releases.json` — последние версии: описание, файлы сборок, контрольные суммы sha256.
- `releases/<версия>/ucms-local-<версия>.zip` — сборка для компьютера.
- `releases/<версия>/ucms-web-<версия>.zip` — сборка для хостинга (Plesk, cPanel, VPS).

Установить вручную: распаковать архив своей сборки поверх папки UCMS (внутри — `cms/`).

Модули — в соседнем репозитории [ucms-modules](https://github.com/ugeenalex/ucms-modules).

Бесплатно для личного использования, коммерческое — по договорённости. См. [LICENSE.md](LICENSE.md).
